        Step 5 · Debrief

        When to reach for which

        Use vector RAG when…

        • You need one specific fact, number, date or quote.
        • The question is vague or topical and names no one.
        • Documents change often. Re-embedding is cheap.
        • Cost and speed matter more than completeness.

        Use GraphRAG when…

        • The question chains relationships (A's B's C).
        • You need a complete list: "everyone connected to X."
        • You want themes or a summary of the whole collection.
        • The answer lives in a document that shares no words with the question.

        Watch out for

        • Graph extraction drops dates, amounts and conditions, which leads to confident wrong answers.
        • Graph indexing costs many times more than embedding.
        • GraphRAG can't start without a named entity in the question.
        • Vector search returns a fixed top-k, so it truncates lists.

        How to interrogate any new corpus

        1. Ask a single-fact control question.
        2. Ask a chained question across two documents.
        3. Ask for a complete list.
        4. Ask a big-picture question.
        5. Ask a vague question with no names.
        6. Ask something the corpus can't answer.
        7. Compare the evidence, not just the answers.

        Or combine them

        Because each approach's blind spots are the other's strengths, serious systems often use both. Common patterns:

        • Routing: check what kind of question it is, then send it to the right search. This is what Hybrid does in the duel.
        • Run both and merge: search both ways and combine the results, often with a ranking model picking the best pieces. Rarely misses, costs more per question.
        • Graph-enhanced vector search: find passages by meaning first, then follow graph connections out from the names in them. This fixes GraphRAG's "needs a name to start" problem. Popular GraphRAG tools such as Microsoft GraphRAG and LightRAG already blend the two internally.
        • Agentic retrieval: give the AI both search tools and let it decide, step by step, which to use and when it has enough evidence.

        Reality check: the most common combination in production is vector search plus old-fashioned keyword search (good for exact names, codes and IDs), plus a ranking model. Full GraphRAG is used more selectively, where relationships really matter, because building the graph is expensive.
